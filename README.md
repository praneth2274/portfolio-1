# Praneth S - Developer Portfolio

An interactive, responsive portfolio website showcasing full-stack projects, certifications, and technical skills.

## 🚀 Features

- **Dynamic Hero Section:** Typing animation & quick call-to-action buttons.
- **Projects Section:**
  - **Socio Learn AI (Apr 2026):** AI-powered educational web app with news summaries, quizzes, and Gemini AI integration.
  - **Smart Currency Converter (May 2026):** Full-stack web app for currency conversion, crypto tracking, and exchange rate analytics.
  - **Water Quality Monitoring System:** IoT embedded system with pH and turbidity sensors on Arduino.
- **Academic & Skills Track:** Timeline layout, interactive skill bars, and credentials tag cloud.
- **Direct Resume Access:** Quick access link to Google Drive resume.
- **Contact Integration:** Contact form with smooth visual status indicators and direct social links.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Vanilla CSS with modern glassmorphism & dark mode styling), JavaScript (ES6+)
- **Typography:** Google Fonts (Space Grotesk & Playfair Display)

## 💻 How to Run Locally

Simply open `index.html` in any web browser:

```bash
# Clone the repository
git clone https://github.com/praneth2274/portfolio-1.git

# Open index.html in default browser
start index.html
```
